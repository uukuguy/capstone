# data-investigation

Choose the investigation from the question and current evidence. No fixed tool order is required.
For open exploration, establish a bounded object/time/metric frame from authorized discovery. Record whether the population is known and why slices were selected. Include low-frequency objects and boundary periods where relevant; do not explore only the largest averages.
For a change question, define the measure, choose a justified baseline and inspect absolute and relative changes with valid counts and coverage. Use alternative baselines when they can test dependence on the reference. Contribution needs explicit compatible, mutually exclusive additive relationships and a retained residual.
For an event question, choose a valid continuous single-object window and distinguish amplitude from normalized shape. Search a finite justified historical range. Match distances and event thresholds are operational definitions, not causal explanations.
Maintain candidate explanations, support, counterevidence and missing observations in shared task state. Select the next slice by its ability to distinguish explanations, new information, business value and incremental cost. Use held-out objects/times and counterexamples; do not validate every discovery on its discovery sample.
Prefer existing result references. Expand source coverage only when it answers a remaining question. At diminishing returns, insufficient quality or a budget stop, deliver findings, selection bias, unevaluated scope and the next useful observation.
Use current Provider contracts and optional guides for exact operations. Do not invent server-side clustering, forecasts, correlations or causal diagnosis. Any authorized local computation must retain inputs and algorithm and remain distinct from Authority evidence.

When the native skill record tool is available, load this exact admitted skill and report meaningful public phases with related tool IDs and product references. Loading does not prove application or successful verification. Use a bounded summary; never include credentials or private reasoning.
