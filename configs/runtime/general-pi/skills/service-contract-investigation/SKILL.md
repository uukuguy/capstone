# Service contract investigation

State the question and identify existing observations that can answer it. Reuse a receipt when it contains the needed facts. Select relevant capabilities from the current authorized publication and inspect their exact contracts.

For a comparison, record the object, metric, units, time zone, interval boundaries, aggregation, missing-value policy and source version when available. Choose a small read-only observation that distinguishes the remaining explanations. State the expected difference before requesting it. Follow explicit continuation instructions and retain partial results, truncation and unknown coverage.

Trace the first observed difference across the model request, gateway call, source response and application projection. Associate observations through admitted references. Record missing stages as unknown. Distinguish elapsed time from summed or nested durations.

For replay, specify inputs, source identity and the property to verify. Compare exact values only for a fixed snapshot. Report confirmed findings, competing explanations and unresolved questions with the corresponding receipt references. Keep real values in their authorized workspace. Use synthetic examples for portable regression cases when permitted.
