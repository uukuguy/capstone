# 小石专有头像

小石是 Capstone 专用 AI 协作者，中文名称为“小石 · Capstone AI”。
GitHub App 身份为 `capstone-xiaoshi[bot]`。

用户已选定第一版：青绿色小石头，额头采用四格标记。

- `avatar-v1.png`：生成原图。
- `avatar-v1.jpg`：同一图像的 JPEG 上传文件，低于 GitHub 的 1 MB 文件限制。

此头像由当前会话使用 imagegen 生成。提交资产不代表 GitHub 设置已经更新。
上传入口：<https://github.com/settings/apps/capstone-xiaoshi>，选择
Display information → Upload a logo → Set new avatar。
GitHub 操作说明：[创建自定义徽章](https://docs.github.com/en/apps/creating-github-apps/registering-a-github-app/creating-a-custom-badge-for-your-github-app)。
