# 局部成果引用：首期协议提案

状态：研究提案，待设计接受；未实现。依据：[代码映射与实验](2026-11-14-code-mapping.md)。

## 范围

现有会话内，从已保存的UTF-8纯文本或Markdown成果选择完整顶层段落，发送局部续作指令，保留原成果、来源和新成果。沿用现有预览、composer、执行与成果机制。

Markdown首期不提供标题、列表、引用块、代码块、表格、HTML及跨段范围的局部选择。界面说明不支持原因，保留现有整份成果引用。含引用式链接的段落必须携带本版本解析出的依赖定义或暂不可选；不允许仅截正文后丢失链接含义。具体依赖提取规则须在实现前确定。此限制是首期交付范围，不是削弱长期业务对象协议。

## 身份字段与归属

| 字段 | 内容 | 生成或检查方 |
| --- | --- | --- |
| schema | 新的局部选择协议版本，保持旧整份引用契约 | 应用 |
| parent_ref | 完整现有ProductRef，不省略归属和版本字段 | 原成果服务 |
| index_ref | 父身份、解析器版本和配置对应的索引身份 | 应用解析模块 |
| block_id | 本索引中的不透明块身份 | 应用解析模块 |
| content_digest | 选中原文的SHA256 | 服务端；客户端可复核 |
| purpose | historical-context | 准入契约 |

客户端不提交自由路径、任意字符偏移或可替代源内容的正文。索引内保存原始源范围、UTF-8字节身份和解析元数据。parent_ref、index_ref、block_id及content_digest共同构成选择键和材料ID输入。显示名称和预览不参与授权。

索引身份需覆盖解析器实现版本、preset、启用规则及规范化策略。原始字节不做静默Unicode或换行规范化；解析时产生的规范化须保留可验证的原文映射。块序号不能单独成为跨版本身份。

## 状态与错误

| 状态 | 行为 |
| --- | --- |
| 索引未就绪 | 显示正在准备；用户可继续使用其他已可用内容 |
| 可选择 | 显示父版本与段落预览，支持选择和取消 |
| 历史可用 | 明示历史版本；用户仍可准确引用该版本 |
| 源版本不可用 | 阻止依赖它的提交；提供重新选择入口，不改成最新版本 |
| 身份或摘要不符 | 拒绝准入，保留当前草稿与已交付成果 |
| 解析器版本不可用 | 重新建立明确的新索引，旧选择不得静默迁移 |
| 范围或格式不支持 | 说明原因；整份引用仍遵循原能力和预算 |

服务端先完成当前用户访问检查，避免错误信息泄露其他会话的对象存在性。具体错误代码与HTTP映射按现有命令拒绝契约设计，不在本研究中创建旁路。

## 提交、并发与恢复

1. UI保存所选块的完整身份，按完整选择键去重，同一父成果可有多个不同块。
2. 提交时服务端重新解析精确父版本与索引，检查内容摘要，再进入原Attempt准入事务。
3. 已接纳的指令保存冻结选择与可恢复输入；之后UI选择、父成果新版本或索引缓存清理不改变它。
4. 相同幂等键返回原接纳结果；不同内容不能复用旧幂等身份。
5. 新成果记录输入来源，并保留旧版；局部续作不自动修改全局目标或替换正式交付物。
6. 草稿恢复与已提交指令恢复分别验证。已提交状态以服务端记录为准。

缓存失效可重建索引，不代表历史成果失效。必要输入无法持久化时准入失败；不能先显示执行成功再发现引用不可恢复。

## 规模与信任

索引和读取采用持久化版本引用、有界分页与预算，不在任务请求中发送完整大文件base64。存储配额、索引预算和模型上下文预算分别设置。当前实验完整读取小文件，仅证明身份机制；GB级后台索引、取消和恢复必须另设接受项。

应用层拥有解析、引用准入与公共投影。Kernel不解释段落或领域对象。历史材料是研究输入；数值与专业结论仍需要本次运行的Authority准入。模型可以解释局部任务，不能扩大引用授权。

## 接受检查

- 同文不同段保持独立，多选不会覆盖输入文件；相同选择去重。
- Unicode、CRLF、空白和解析器升级不造成错误定位。
- 链接定义、HTML及嵌套结构不会被无提示地截成失真内容。
- 伪造归属、块身份、摘要或索引版本被拒绝，且不产生任务状态变化。
- 准入后源暂不可读时，原幂等重试仍使用已冻结输入。
- 真实模型续作交付新成果，旧版摘要不变；数据库恢复、刷新与会话切换后可查看来源。
