# Capstone application design references

These source documents and mockups are preserved for product and interaction
research. Their file versions are reference-document versions, not application
release versions. Archiving them does not change the accepted enterprise design
or claim frontend implementation or acceptance.

Implementation continues to follow the accepted
[enterprise baseline](../superpowers/specs/2026-10-15-enterprise-design-final.md),
[UI contract](../superpowers/specs/2026-10-15-enterprise-task-ui-design.md) and
[workspace prototype](../design/enterprise-workspace-prototype.html).
Any new decision must be reconciled with those owning sources before implementation.
