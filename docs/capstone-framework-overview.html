先说清楚：它是做什么的

和智能体对话，完成专业分析。

Capstone 是一套用来搭建专业分析助手的软件框架。你在对话框里用中文描述任务，智能体根据已登记的模型和工具执行分析，再把结果、图层、报告和依据带回来。仓库中的电力分析工作台，是用这套框架做出的第一批应用。

比如，电力工程师可以直接问：“检查线路负载，列出需要关注的线路。”智能体会先读取当前电网模型，再调用电力计算程序，最后用人能看懂的方式回答。

04 / 为什么结果值得信任

数字从哪来，能不能查到？

涉及数值的分析会保存本次使用的模型版本、计算结果和依据。读报告时可以沿着这些记录回查。文字解释仍需结合分析范围和专业知识判断。

要记住：普通资料问答不会产生计算记录。计算结果有来源，也不等于每一句文字解释都已被证明正确。

计算由专业软件完成

例如，pandapower 负责静态电网计算，PyPSA 负责能源系统的建模、运行和规划。

只看这一次的依据

答案引用的是本次运行拿到的模型、结果和证据。不会把旧运行的数字悄悄拼进来。

失败会明确显示

如果答案或依据没有保存成功，系统会明确报失败，不会把半成品包装成完成结果。

技术团队补充：为什么要拆成四层？

因为“用户怎么用”“领域规则是什么”“一次运行怎么管理”“业务系统怎么算”是四类不同工作。应用、领域能力包、运行内核和登记系统各自负责一类事情，换模型或接入新领域时，不会把整套系统绑死在一个业务系统里。

各自保管数据

开发环境和用户环境不共用数据库、文件存储、令牌、大模型服务凭据或运行数据。

07 / 用户怎么操作

打开模型，和智能体对话，完成分析。

App 是给人的工作台：先选一个已经登记的模型，再和智能体对话。你可以逐条下指令，也可以让它按分析流程自动完成；每一步的结果都留在同一条分析记录里。

分析记录中包括：答案、模型图、结果图层、执行过程、完整报告和本次运行用过的依据。浏览器通过 API 读取经过检查的结果，不直接访问后台文件存储。
