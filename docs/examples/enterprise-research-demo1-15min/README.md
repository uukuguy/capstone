# 企业研究模拟样例 · 15 分钟版

按用户审核意见，将原六小时演示改为十五分钟时段。全部为合成数据，覆盖 2026 年 8、9 月，三省、两个有向通道；每天 96 个时段，共 46,848 条记录。每条功率记录的积分时长为 0.25 小时。

价格、出力及潮流含十五分钟变化，负价窗口、触底、动态限额和缺失区间均重新生成；不是复制原记录或仅修改时间标签。原六小时样例保留用于历史运行复核。

只上传 inputs 下的 README 和三份 CSV；不要上传 verification。资料共 5,290,201 字节。业务统计口径见 [输入说明](inputs/README.md)。

使用企业研究与分析 ApplicationProfile，通过普通文件和通用智能体工具完成计算与报告。该样例不增加专用业务接口，不证明真实市场结论。

verification/generate.py 可重建输入与独立聚合基准；ground-truth.json 仅供核对。分析报告须使用新数据重新计算，不能引用旧六小时报告的数值作为新结果。
