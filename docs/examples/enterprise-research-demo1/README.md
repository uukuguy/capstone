# 企业研究模拟输入样例

这是普通文件分析样例，用于验证企业研究的资料读取、计算、图表、报告及后续引用链路。
全部数据均为模拟数据，不对应真实省份、市场或调度结果，不能作为真实业务结论。
它不是专用 Capstone 接口、固定工具流程，也不是已经通过真实业务验收的声明。

## 使用范围

只把 [inputs](inputs/) 中的四个文件一起上传给被测智能体：

- [README.md](inputs/README.md)：时间、单位、业务口径、缺失值及分析限制。
- [spot-prices.csv](inputs/spot-prices.csv)：甲、乙、丙三省的模拟现货价格。
- [interprovincial-flows.csv](inputs/interprovincial-flows.csv)：两个有向通道的计划、实际及动态限额。
- [renewable-generation.csv](inputs/renewable-generation.csv)：预测、可用、实际、正式限发及其他运行减发。

输入覆盖 2026 年 8、9 月的六小时时段，共 208,264 字节。输入说明只包含资料口径；
任务目标由用户用普通自然语言另行提出。可要求比较价格、通道与新能源情况，生成可核对的报告和图表。

## 独立核对

[verification/ground-truth.json](verification/ground-truth.json) 仅供评测者核对，**不要上传给被测智能体**。
它保存关键聚合值、数据覆盖、反例及四个输入文件的字节数和 SHA256。
核对时先检查输入哈希，再比较模型保存的计算结果；不要以模型文字代替独立核对。

负价不等于触底；计划超限不等于实际越限；预测偏差不等于正式限发。
缺失值不能补零，已知时段的结果不能冒称精确全月结果。图表、文件可打开与业务结论正确应分别检查。
保留失败和限制；单次样例走通不等于已验证真实企业数据或通用研究能力。
