## 行为变化

- 初始化只取得有界摘要目录，不取 tools/list、全量 describe 或虚构占位 Schema。
- 按模型实际选择批量取得精确输入及已声明输出 Schema。验证稳定身份、授权视图、
  工具版本和分段指纹后，才激活菜单或执行组合程序。
- 使用公开 SDK send_request 执行，避免 call_tool 隐式调用 tools/list。
  每次派发携带发布与工具版本绑定；参数和成功输出仍由客户端校验。
- 缓存按实例、授权视图、组合工具身份及版本隔离，并限制内存占用。发布快照不因
  加载 Schema 而变动，任务授权和执行回执仍绑定原快照。
- 只对结果明确返回的续接动作补取相关契约；补取失败不丢失已经返回的源端观察。
- 服务总线失败与网关传输失败分别处理。前者保留独立元数据工作；后者按原任务
  停止规则阻止继续远程探测。网关禁止重试的相同操作不能用新调用 ID 自动重放。
- 过程摘要显示失败阶段、连接/发送/结果状态及下一步约束，不推断已取消。
