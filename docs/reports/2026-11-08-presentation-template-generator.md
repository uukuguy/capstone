## Reusable mechanism

This capability belongs to the application/native report workflow. The model owns
interpretation and report organization. The renderer owns literal composition,
source/path validation and layout bounds. Neither a renderer receipt nor another
model's critique establishes Authority truth. The Kernel and Domain Pack grants
are unchanged. There is no topic keyword router or fixed first tool action.

capstone-report1.2.0 adds capstone-presentation/2 for new template evidence briefings.
Each ordinary content record requires argument.explanation as nonempty literal
text. The renderer appends that authored explanation to visible blocks and applies
the actual page budget. Missing/invalid explanation fails; overflow fails rather
than shrinking, silently splitting or dropping reasoning. Receipt.visible_arguments
binds the rendered page and explanation digest. It preserves the original spec
hash. Agenda and closing omit argument. Version1 and the original untemplated
baseline remain compatible. Presence and rendering do not certify reasoning.

The model reviews actual visible text, excluding notes. It checks the evidence-to-
claim inference, comparison basis, scope, contrary readings and chapter relevance.
When the application grants the existing isolated text pool, scoped readers receive
visible text and admitted facts, excluding the author's notes, argument plan and
self-review verdict. They have no tools, files, new source grants or Authority
access. The parent checks actual findings and records dispositions before revision.
No case-specific chapters, metrics, desired conclusions or prose-count rules were
added. Native content/visual review and source verification remain distinct.

A real execution defect appeared in V11: collect(ids,wait_ms) ignored wait_ms and
returned immediately.4a638740 adds selected-ID waiting in the neutral async pool.
Unrelated completion cannot satisfy it. Timeout preserves running work without
cancellation or resubmission. Zero-wait saved-result reads retain their behavior.
The reader assignment is also bounded to coherent questions/sections, not an
unbounded per-page review essay. This is a general execution/composition fix.
