# 执行记录窗口在对话底部的高度修复

用户反馈：执行指令时，位于对话最底部的执行过程记录窗口不能自动增长到最大高度。

根因：`CapstoneAssistantThread.tsx`按记录窗口当前顶部至对话可见底部的剩余空间计算`maxHeight`。窗口接近底部时，剩余空间不足，使高度上限停在80px；即使对话仍在跟随执行，也无法利用外层滚动继续展开。

修复`076f0d14`：执行中且对话滚动位置距底部小于20px时，使用既定最大高度上限（对话视口72%与窗口65%中的较小值，最低80px），允许内容自然增长。用户上滚阅读历史时继续使用当前位置的可用空间限制。没有强行定位指令、填充固定空白或将短内容拉成空窗口。

验证：新增回归测试先复现80px而非360px；修复后验证底部允许360px、上滚恢复80px。142项完整对话组件检查和类型检查通过；doctor与diff检查通过。浏览器实时长过程截图尚未验证，单元几何模拟不能替代实页滚动验收。
