# 切片视图的时间窗契约交接

Capstone 在 local-dev 5174 验证薄上下文。第二条会话首次调用
`run_slice_view` 时传入了无时区的时间，网关返回
`invalid_metric_slice`，要求两端带时区且开始早于结束。加上
`+08:00` 后查询成功。会话 ID 为 `thr_be832c9e7a8b0c598840`。

从同一网关连接按渐进契约发现读取精确 `inputSchema`，两字段均为
`string | null`，默认 `null`。Capstone 现有派发前校验按该
Schema 接受带偏移和无偏移的值。网关的量测时间窗校验随后拒绝无偏移的值。
业务约束需要由网关随视图参数契约发布。

## 建议发布

- 在适用的视图详情和返回动作中，为该视图发布可机器读取的时间窗参数约束。
  声明何时必填、时区形式、查询端点规则，以及开始早于结束。给出带偏移的
  可直接调用样例。
- 保留通用操作的不同形态。无时间窗视图和只传 `page_ref` 的续页需要继续可用。
  如果所有适用输入都遵循同一字符串约束，可将它放在公开输入 Schema 中。
  依赖具体视图的规则应随视图契约发布。
- 请回传操作和契约版本、精确 Schema、视图参数声明的位置，以及合成样例。
  联验覆盖缺少时区、带偏移、结束早于开始和原引用续页。客户端继续按当前
  发布修订取契约，并用原引用及当前授权执行续页。
