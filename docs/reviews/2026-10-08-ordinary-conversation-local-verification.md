# Ordinary conversation with no calculation tools

## Scope and behavior

The approved mainline baseline §5.1 and empty-capability decisions govern this
change. Empty selection is a valid Capstone business Context. It uses the same
Attempt, events, cancellation, saved model identity and replay contracts.

- Web submits the exact compatible enabled selection, including an empty list.
  Missing catalogs still preserve the draft and require reconnection. Registered
  scripted cases still require their calculation tools.
- Both registered hosted adapters provide their stage-owned workspace root for
  an application-only Pi RPC session. That session has no domain extension,
  built-in tools, domain policy, Authority handle, or prior result references.
  It retains bounded application metadata, model identity and previous reader text.
- Application catalog metadata describes registered tool groups without enabling
  them. Ordinary replies have general-knowledge or catalog-information assurance,
  with no Authority result or evidence references.
- Generic domain explanations route ordinary. Model facts or calculations retain
  professional admission. Zero-tool professional Turns return `capability_required`
  before constructing a Provider runtime. Routing remains a bounded heuristic;
  it does not prove freeform answer semantics or grant tools.
- Empty contexts skip domain topology projection and release resource pins.
  Baseline model browsing remains an application-owned Authority operation.
