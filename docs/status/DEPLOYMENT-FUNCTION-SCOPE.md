### 现用文件账本是否仍必要

目前必要。这里的 core/context-events.jsonl 是执行状态账本，不是可任意删除的调试日志，也不是 Thread 对话历史的文件副本。

- Kernel runner 初始化 store，projector 写入已准入结果引用及领域状态，turns 写入启动、答案提交和完成记录。
- grid-agent 的 SingleRunCompatibilityAdapter.read_committed_answer 读取该账本，验证唯一答案提交、所属运行及答案引用；Kernel _persisted_answer_assurances 同样依赖回放核对答案。
- Hosted reference_handoff 仍使用该 store 校验交接收据；PostgreSQL capstone_thread_events 未提供这些存储/回放 API 的等价替代。

因此保留现用账本，归档未采用的 OP-13 重写方案。文件格式或存储后端可以未来替换，但须先覆盖现有写入、答案绑定、回放和历史兼容入口；本次不发起迁移或删除。旧 grid-agent analysis/store.py 另有逐条追加的日志实现，不能把 OP-13 全量重写基准推论到所有 JSONL 文件。
