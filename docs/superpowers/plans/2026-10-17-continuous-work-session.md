# 持续工作会话实施计划

**Goal:** 在现有Thread/Work/Attempt链路上实现用户主导、对象承载、可持续引用和多次输出的工作会话。
**Architecture:** Application拥有入口与公开投影；Kernel组织中性上下文、事件与制品关系；Pack拥有业务方法与校核；Authority事实仍走原准入契约。
**Tech Stack:** 现有Python服务与账本、React工作台、既有事件及快照协议。
**Design:** [已确认约定](../specs/2026-10-17-continuous-work-session.md)。
