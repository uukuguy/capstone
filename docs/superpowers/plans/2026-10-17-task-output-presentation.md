# Task output presentation implementation plan

**Goal:** Present task-owned business results in the workspace and keep inspection and diagnostics in answer-owned sheets.

**Architecture:** Keep the existing admitted result chain. The owning Pack adds optional presentation membership from verified Authority context. The application persists that contract through the result projection; clients render membership, never infer it from names or order. Existing records without membership remain inspectable. A result collection is not an assertion that a final report or complete scenario comparison exists.

**Work object:** Distinguish the task objective from its primary resources. Grid tasks use a versioned model; enterprise research uses an authorized document/interface set; ordinary questions may have none. The accepted task context owns these references and revisions. A profile supplies defaults, not a mandatory resource requirement for every message. Preserve per-instruction historical context. Do not fabricate missing research resources in this grid-focused slice.

**Session scope (user steering):** Provide professional task sessions and a general chat entry for basic conversation and chain testing. Ordinary Q&A remains shared behavior, not a third professional capability. Initial entry presets constrain complexity: grid entry selects one primary model; research entry selects documents/interfaces; general chat binds no professional object. Do not expose mixed-model composition or session conversion in the first iteration. Preserve the protocol's explicit object and revision ownership for future extension. Session types and resource entry are accepted design, not implemented by this result-presentation slice.

## Acceptance

No generated scenario names, ranking, result status, or final-report claims in the browser. The first slice may show neutral running-state groups where the Authority has no descriptive label. Historical records are not silently backfilled with guessed metadata. User-facing output and technical inspection retain the same admitted result identities.
