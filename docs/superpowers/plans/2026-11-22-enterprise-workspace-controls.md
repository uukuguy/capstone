# 企业工作台控件实施计划

沿用[企业工作台交互合同](../specs/2026-10-15-enterprise-task-ui-design.md)。验收范围为 local-dev。

1. 输入区显示当前 Goal 或 Mission 状态。可在同一区域暂停、继续、查看计划或复制续作引用。相同会话的输入工具在历史查看时保留位置。禁用会改变当前任务的操作，保留历史草稿与原请求恢复。
2. 顶栏保留会话名称和导航。历史列表用单行标题，完整标题可查看。单条回复继续提供复制、成果和执行详情。右栏按任务计划、成果、过程记录分页，保留键盘切换。
3. 检查 1440px 和 430px 的历史恢复、状态栏、右栏切换和回复详情。验证历史草稿不会被替换，返回当前对话后可继续操作。
4. 用实际 local-dev 回执运行交付审查。要求交付验收矩阵与评审报告。独立下载并校验两份文件，逐项核对通过、有问题与未验证的判定。记录各模式的实际终态。

## 实测发现

Instruction 和 Mission 交付两份文件并通过下载核对。Goal 首步只收到计划子指令。首步没有取得原指令中的证据正文，只交付一份缺乏证据的 CSV。自动复盘以部分完成结束。后续修复须核对每一步能读取已接纳的原始证据，并在仍有可执行步骤时继续推进。此项后端问题独立于页面控件验收。
