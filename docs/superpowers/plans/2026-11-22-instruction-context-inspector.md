# Instruction context inspector
验收范围为 local-dev。保留工作台输入区、回复和右栏的现有分工。

1. 在原生模型调用边界记录请求身份、配置窗口、估算构成和 Provider 回执。只发布数值，不发布模型输入。
2. 使用公开事件的会话、Instruction 所属 turn 和执行尝试绑定。重试共享 turn，后续指令另有 turn。
3. 输入区显示主链最近一次输入占用。回复旁入口打开同一个右栏并按 Instruction 筛选。使用时间线组织请求和压缩，选中记录固定显示明细。
4. 校验部分记录、并行调用、历史重试、窄屏和键盘。使用真实任务验证用量、压缩与两个入口。

## 分类下钻与指令关联

参考 Magpie 的分类概览、条目列表和展开方式，沿用 Capstone 右栏。色块和分类列表都能悬浮或按键聚焦并选择。保存每类条目的位置、类型和估算量，工具名称仅在可发布时显示。读取旧记录时保留分类合计，并说明条目是否可用。

会话范围用指令筛选器和时间线标题标明调用的归属。选中请求后，在属于该请求的回复旁显示调用编号。定位回原指令时保留右栏与所选详情。

## 从执行过程读取单次请求

执行记录使用实际调度请求 ID 打开对应上下文。右栏定位到本次请求，保留指令归属。工具返回可依托同会话中已发布、标识唯一的工具事件展开已有片段。系统提示和完整请求正文仍需明确可读字段、授权及保留策略。

## 请求首屏与双向定位

首屏显示所选请求的用量、缓存命中、分类和条目。请求趋势放在详情之后，完整调用与压缩历史默认折叠。按类别筛选同一条目列表。收起未展示的条目，显示实际记录范围。

执行记录中的模型请求使用行内图标。单次主链调度的图标位于模型行，调度回执仍可展开。右栏用执行尝试和调度 ID 定位实际调用，并打开该回复的执行过程。宽屏保留上下文，窄屏收起覆盖对话的右栏。使用已保存的真实任务确认双向选择相同请求、右栏状态及焦点。
