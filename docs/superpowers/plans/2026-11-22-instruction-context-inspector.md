# Instruction context inspector
验收范围为 local-dev。保留工作台输入区、回复和右栏的现有分工。

1. 在原生模型调用边界记录请求身份、配置窗口、估算构成和 Provider 回执。只发布数值，不发布模型输入。
2. 使用公开事件的会话、Instruction 所属 turn 和执行尝试绑定。重试共享 turn，后续指令另有 turn。
3. 输入区显示主链最近一次输入占用。回复旁入口打开同一个右栏并按 Instruction 筛选。使用时间线组织请求和压缩，选中记录固定显示明细。
4. 校验部分记录、并行调用、历史重试、窄屏和键盘。使用真实任务验证用量、压缩与两个入口。

## 分类下钻与指令关联

参考 Magpie 的分类概览、条目列表和展开方式，沿用 Capstone 右栏。色块和分类列表都能悬浮或按键聚焦并选择。保存每类条目的位置、类型和估算量，工具名称仅在可发布时显示。读取旧记录时保留分类合计，并说明条目是否可用。

会话范围用指令筛选器和时间线标题标明调用的归属。选中请求后，在属于该请求的回复旁显示调用编号。定位回原指令时保留右栏与所选详情。

## 从执行过程读取单次请求

执行记录使用实际调度请求 ID 打开对应上下文。右栏定位到本次请求，保留指令归属。工具返回可依托同会话中已发布、标识唯一的工具事件展开已有片段。系统提示和完整请求正文仍需明确可读字段、授权及保留策略。

## 请求首屏与双向定位

首屏显示所选请求的用量、缓存命中、分类和条目。请求趋势放在详情之后，完整调用与压缩历史默认折叠。按类别筛选同一条目列表。收起未展示的条目，显示实际记录范围。

执行记录中的模型请求使用行内图标。单次主链调度的图标位于模型行，调度回执仍可展开。右栏用执行尝试和调度 ID 定位实际调用，并打开该回复的执行过程。宽屏保留上下文，窄屏收起覆盖对话的右栏。使用已保存的真实任务确认双向选择相同请求、右栏状态及焦点。

## 研发诊断的请求内容与来源

此节定义后续实现。已有界面提供请求身份、用量和部分工具输出片段。

### 状态与请求

- **任务状态**保存恢复所需的目标、约束、进展、待办、校验依据和产物引用。会话可以没有明确任务。Goal 或 Mission 恢复时读取任务状态，再根据当前指令和授权重新组装输入。
- **组装记录**保存每个输入条目的来源、版本、选择原因及纳入范围。保留来源时记录具体文件区段、已加载技能版本、记忆条目、历史消息、工具调用或压缩记录。上下文预算裁剪记录受影响条目及原因。
- **请求快照**在调度实际开始、SDK 完成输入变换后采集。保存模型输入的语义结构、顺序和最终纳入范围，并与执行尝试和实际调度请求绑定。等待队列只显示调度状态。Provider 回执更新用量和结果，原快照保持固定。Provider 适配层额外转换有单独的阶段标记。

### 请求载体与来源

请求载体保留系统提示、工具定义、消息、工具返回、结构化或多模态块的原结构。工具定义可查看名称、描述、参数 schema 和发布版本。消息可查看本次实际送入的正文和角色。工具记录可对应调用参数、工具执行及模型实际收到的结果。

来源标签独立于载体。系统规则、运行环境、技能、记忆、文件片段、历史消息、工具执行、压缩摘要和任务交接都可以是来源。例如文件内容通过工具返回进入模型，载体为工具返回，来源仍指向对应文件版本及区段。来源由组装边界传递，缺少证明的条目标记为来源未记录。按来源聚合时，同一内容块只计一次，附带的来源引用可以有多个。

压缩记录关联压缩前快照、摘要请求、生成的摘要、保留边界和压缩后的首个请求。跨请求比较显示新增、移除、改写和保留条目，尤其要能看出此前用户约束和校验条件是否进入后续请求。

### 本地存储与呈现

请求正文写入私有诊断存储，按会话、执行尝试、调度请求和条目索引读取。普通公开事件只保留请求标识、用量、摘要以及覆盖状态。研发入口由后端验证会话和诊断读取权限。凭据及受保护字段在写入前处理。文件和长工具返回使用版本化引用、按需分页读取和独立预算。条目区分完整、截断、遮蔽和未采集，采集失败可诊断并允许任务继续。

右栏首屏展示所选请求的模型、状态、用量、来源构成和条目。悬浮或聚焦预览，点击查看正文、来源和纳入范围。调度请求、指令、工具执行和压缩记录按实际标识互相定位。历史记录缺少快照时继续展示现有数值及公开片段。

### 实施顺序与验收

1. 在普通通用执行、分析调用与压缩摘要请求的组装及调度入口接入一致的条目标识。先验证请求快照与实际调度对应、顺序正确及敏感字段处理。
2. 接入私有快照的摘要索引与逐条内容读取，复用已存在的执行记录入口。用真实任务检查提示段、工具 schema、消息及工具结果，并验证刷新后仍可定位。
3. 接入文件、技能、记忆及交接的版本与区段来源。用真实多轮任务覆盖注入、裁剪、压缩、会话结束与恢复，验证用户约束在跨请求和跨会话中的去留。回归等待取消、重试、并行请求和旧记录。

### 本地正文试用

用 `CAPSTONE_CONTEXT_DIAGNOSTICS=1 make capstone-local-rebuild` 在本地启用。捕获只影响之后实际调度的请求。右栏用「读取诊断记录」加载条目索引。开放会话中可向该入口提供操作员凭据，凭据只保留在当前界面内存，普通会话请求的访问模式保持原样。索引和正文均需要操作员权限，正文按条目请求。当前实现保留明确的组装块和工具调用标识，按同一执行任务的相邻同类请求比较已采集内容。文件与技能通过执行回执关联版本和区段。会话历史、已选交接和压缩摘要使用实际注入块标注来源。未传递来源的条目保持未归因，媒体只列类型。诊断对象的自动清理和跨会话逐条版本链仍需验收。
