# CAPSTONE 工作台桌面可读性与侧栏定位设计

日期：2026-09-27。基线：`941fdfb`。本设计只调整工作台页面的呈现与滚动，不改变案例、执行、证据或报告数据。

## 目标

在 1280–1920 px 桌面视口中，保留当前浅色三栏、顶图原图和中栏内容顺序，同时让正文和控件以真实可读的 CSS 像素显示。查看长页面时，标题栏保持在视口顶部，左右栏保持在标题栏下方，案例与状态始终可访问。

## 方案

- 移除 `.app-shell` 的全局 `zoom: .67`。以明确的页面最大宽度、左右等宽栏、中栏内边距和字体尺寸恢复当前视觉比例。1280 px 页面不得水平溢出；1920 px 仍居中留白。顶图原图、文字内容和电网图样式不变。
- 桌面三栏中，顶栏使用 `position: sticky`，侧栏使用 `position: sticky`，顶距等于顶栏实际高度；侧栏高度受视口限制。侧栏内容超高时，在自身区域滚动，不遮住标题栏或中栏。中栏继续使用页面滚动。
- 在平板两栏断点，只保留可容纳的左栏定位；运行详情仍在中栏下方。680 px 以下沿用当前纵向布局，不设置侧栏吸顶，也不产生横向滚动。
- 优先让案例说明、正文和报告可读，按钮拥有足够操作高度。英文眉标和辅助元信息仍保持次级，不通过整页缩放制造密度。

## 失败与回退

若局部区域因放大换行，应在该区域调整行宽和留白；不得恢复全局缩放。若某个断点的侧栏高度不足，侧栏内部滚动应保留标题和可辨认的滚动边界。任何宽度出现遮挡或水平溢出，先回退对应断点的定位规则，不改变案例执行逻辑。

## 验收

1. 375、768、1280、1920 px 截图与基线对比：顶图原图和中栏宽度关系保留，页面无横向滚动。
2. 1280、1920 px：案例说明和报告正文比基线明显易读；电网操作按钮不再只有约 23 px 的实际高度。
3. 1280 px 长页面滚动：顶栏和左右栏标题仍可见；右栏状态、左栏案例可操作；侧栏内容超高时能独立滚动。
4. 375 px：纵向阅读、案例切换和自动完成按钮仍可操作；不引入固定侧栏或遮挡。
5. 运行 App 的聚焦测试与构建；只在有具体风险时扩大验证。
