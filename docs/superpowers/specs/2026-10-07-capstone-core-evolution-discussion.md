## 用户已明确的方向

1. **专业对话是一条需要持续发展的产品线。** 用户通过对话熟悉智能体驱动的底层科学计算工具，了解能力并完成一次性常规工作。应继续向专业、易用、强大发展。
2. **复杂分析的自主推进属于更高阶能力。** 不能把它生硬地加入现有对话模式。其交互、任务组织和运行方式需要结合实际工作继续讨论。
3. **Capstone 需要逐步对接实际电网工作。** 用户举出的工作包括全网一次接线的潮流计算、电网运行方式分析、全网 N-1 运行实验。目标是承担原先需要大量人力和时间的工作。
4. **知识、工具和技能无法在开发前一次准备齐全。** 框架需要持续接入 skills、专业工具等能力，并支持实际使用。
5. **演进研究是长期工作。** 讨论可能伴随整个开发阶段，围绕本笔记持续展开。
6. **强大的业务能力基座与自主推理组织共同构成目标。** 用户于2026-10-11确认基础框架负责统一业务任务执行完备；Capstone Agent还应基于已有领域知识、工作方法和可执行能力，组织知识体系未预先写出的任务路径，开展长程、开放式、可证伪的计算研究，输出人类可理解、机器可复核、证据可追溯、结论可重放的研究记录。预设流程不是任务范围的上限；此项是已接受的产品方向，具体协议和实施计划尚未确定。

这些方向明确了产品与框架问题，尚未确定所有接入机制、任务协议、界面和实现顺序。

## 统一电网模型体系：高级能力，延期

- **用户定义**：ApplicationProfile 在电网语境中对应一套电网计算分析工具；规模较大的工具体系可以组合多个 Domain Pack。用户手动启用／禁用工具组是必要功能。
- **评估对象**：建立完整的、独立于计算工具的统一电网模型体系，使同一电网可供多种工具操作；仅 pandapower 与 PyPSA 两工具互转不构成本议题的目标。
- **助手判断（建议，未批准实施）**：若 Capstone 长期围绕同一电网组合多种分析工具，该体系具有基础价值。统一模型身份、设备与拓扑语义、参数单位、场景／时序、版本、变更、转换和结果证据关联，可减少各工具维护互不相干模型造成的漂移。完整体系应有可扩展的领域语义与工具专有扩展，不要求每个引擎支持全部字段，也不承诺任意工具无损操作任意模型。
- **复杂性与边界**：转换后的任务适用性、缺失数据、近似与信息损失必须可判定和追踪；会影响目标任务正确性的缺失不能默默忽略。领域模型及转换由相关 Domain Pack 与 registered Authority 承担；Kernel 保持中立。后续需要专项设计与工程估算，当前没有开发成本或效果验证结论。
- **参考来源**：[ENTSO-E CGMES Library](https://www.entsoe.eu/data/cim/cim-for-grid-models-exchange/)包含运行与规划模型交换、模型管理及相关规范；[pandapower3.4.0 CGMES 导入](https://pandapower.readthedocs.io/en/v3.4.0/converter/cgmes.html)提供现有标准接入参照；[PyPSA1.3.0 pandapower 导入](https://docs.pypsa.org/v1.3.0/api/networks/io/#pypsa.Network.import_from_pandapower_net)明确列出不支持的组件／状态。这些来源可支持后续评估，不证明 Capstone 已实现统一模型体系。
- **用户决定**：即使建设，也属于高级能力，现在不会马上实现。保留为后续议题，不启动实现，不改变既有智能体对话主线；当前工具选择继续遵守现有兼容范围。
