# 企业任务界面与前后端交互契约

2026-10-16共同基座决定：本工作台属于企业自主执行应用，不能替换或强制升级
阶段完整的智能体对话应用。会话传输、事件状态、成果渲染、图表、拓扑及来源查看
组件由两应用复用；对话保留即时交流，自主执行强化持续任务与成果管理。
两类工作视图统一命名为“业务分析与报告”和“模型分析与决策”，可在同一任务组合。
通用前端修复须验证两个入口受影响的行为；新工作台专属交互不成为共同组件的必需条件。

状态：已纳入[设计定稿v1](2026-10-15-enterprise-design-final.md)，未实现运行界面。依据[统一执行设计](2026-10-15-pi-enterprise-execution-design.md)。
本设计覆盖同一主链路的简单问答、实时检索和Demo1分析，不新增普通/专业入口选择。

## 已确认的产品形态与视觉方向

一次性统一设计通用AI工作界面，使用全页面宽度，主界面为对话，支持动态artifacts和
多会话管理。可以提供任务相关的约束与固定操作，不要求无限自由布局或用户自行编排流程。
Demo1和Demo2是统一框架中的不同工作视图，不能把它们做成两个独立产品或两套任务协议。

交互原型：[企业工作台](../../design/enterprise-workspace-prototype.html)。
异常与任务控制：[七类交互状态样例](../../design/enterprise-state-review.html)，已检查桌面/手机和本地状态转换。
原型使用本地示例状态，不调用模型、业务服务或专业计算；会话与草稿保存在本机浏览器，支持重置，
文件选择只记录文件名，不上传文件。原型中的场景标识仅用于切换样例，不能进入运行路由。

任务进展由明确标注的演示按钮驱动。图表页使用标明合成来源的样本，支持查看数据与导出SVG；
这些交互不代表后端研究、恢复或专业图表管线已经实现。
正式图表须符合[执行与成果契约](2026-10-15-enterprise-execution-contracts.md#7-专业级图表是通用产物能力)：
预览、数据、方法、来源、版本和报告级导出共同构成成果，不以截图替代可复现的图形交付。

Demo2已补齐同框架下的场景与方案、影响图表、验证依据三个交互视图。
电网图已按用户要求替换为[已有IEEE-39电气拓扑](../../design/ieee39-recorded-topology.md)，
复用现有组件导出的布局和符号，支持缩放、平移与适配全图；拓扑为已记录数据，非当前运行结果。
用户可切换故障后/候选A/候选B，查看同一选择的合成线路负载率、节点电压和验证明细；
这些合成指标不绑定IEEE-39，不在其拓扑上叠加故障或数值。正式产品的联动要求见下方视图契约。
修改约束的示意操作将旧结果标为失效，保留比较能力。A演示热限额改善而电压仍未通过，
B只演示所列数值检查通过，功率平衡、收敛和独立AC复核仍明确未完成，不能显示全局“可行”。
分析数值为内置合成数组，不存在模型计算或当前任务Authority证据。导出分析图形也包含合成及失效标记。
原型脚本[Demo2交互](../../design/enterprise-decision-prototype.js)仅用于设计，不进入产品运行路径。

以下为专业视图扩展的电网案例说明，只在对应应用选择该能力并提供相应投影时适用。
故障、候选、电压等字段属于专业投影，不成为统一工作台必填项或固定页签。
正式使用此案例时遵循以下视图契约：

- 当前选择由任务、模型修订、运行快照、故障场景、约束修订、候选方案修订共同定位。
  切换选择后，网络、表格、图形和验证卡使用相同身份，晚到结果不得覆盖新选择。
- 计算中、失败、无可行解、结果待验证、验证未通过、验证通过和旧结果失效分别呈现。
  尚未计算时不显示零越限；求解器成功不等于独立验证通过，验证通过不等于已证明最优。
- 图形由专业Pack公开的有界结果投影驱动。网络图显示拓扑而非虚构地理位置；节点电压用离散点，
  热限额按适用类型和版本呈现。缺失设备、未收敛结果和显示子集须说明，不能显示成全网正常。
- 候选比较展示目标与代价、调节量、切负荷、越限和验证状态；禁止不同快照或不同口径直接排名。
  对比显示不执行调度；写入或执行操作需要另有明确授权和已注册能力，不因选中方案触发。
- 用户调整目标后，由自主研究决定补查、计算、提出候选或说明不可行。页签是查看方式，不是固定工作流。
- 通用Pack可协助报告和图形编制，但数值与专业验证身份来自授权的专业结果；图形自身不产生新的仿真证据。

采用ui-ux-pro-max的排版、清晰层级、真实操作反馈、对比度与键盘交互原则。
其自动检索的营销页面结构不适合工作台，不采用该页面模式。
视觉提案：石墨绿导航、暖白对话区、纸张质感的成果区；避免彩色卡片堆叠或大面积装饰渐变。
主色#245b47，正文#22352e，背景#f8f8f4，分隔线#dde1d9。
界面采用系统无衬线字，报告标题采用本地中文衬线字体回退，不依赖外部字体请求。
全宽指工作台占满视口；长段文字仍控制行长，剩余空间用于对话、成果与专业视图协作。

多会话支持新建、切换、重命名和归档；各自保留草稿、目标、资料、产物及选中版本。
切换会话不暂停后台任务，不将一个会话的模型或资料带入另一个会话。
归档是导航操作，不隐式取消正在执行的任务；运行中归档须明确提示后台状态。
已归档会话可恢复，删除不作为首版默认操作。

## 统一框架下的工作视图

下表是示例视图组合，不是穷举业务分类。统一工作台按已注册的产物schema与版本加载
可信视图；同一任务可组合任意获准视图，不以Demo名称或两类任务分类决定布局与执行。

| 工作视图 | 主要内容 | 明确约束 |
| --- | --- | --- |
| 轻量对话 | 回答、必要来源与输入 | 不强制展开研究或成果面板 |
| 分析与报告（Demo1） | 对话、资料状态、报告/图表/数据artifacts、依据和版本 | 原生外部资源支持通用分析，不要求专用Pack |
| 模型与决策（Demo2） | 对话、模型与运行快照、场景、候选方案和验证对比 | 专业结果来自注册能力，不以界面示意代替计算 |

应用登记可信视图组件与所支持的公共资源/产物类型。选择视图依据任务配置和实际
公共投影，不根据用户句子关键词，也不远程执行Pack提交的任意前端脚本。
Profile可声明首选视图；用户可以收起或切换已可用视图；未知类型回退到安全的通用成果展示。
同一任务可同时拥有报告与专业模型视图，界面切换不改变推演状态、授权或事实来源。
任务视图是呈现方式，不能用它隐式选择另一套智能体执行链。

动态artifacts由真实事件驱动：创建草稿、保存可预览版本、更新、失效和完成分别呈现。
只展示已保存的完整版本，不把半写入的文件当最终成果。用户正在查阅旧版时，
提示有新版本而不抢占其视图；切回最新版本有明确操作。报告、图表、数据和专业结果
共用身份/版本/依据契约，由不同可信组件呈现，保留适用的专业检查范围。

## 信息架构

ApplicationProfile在界面上称为“业务能力组”；默认不显示内部类名、binding或执行器角色。
工作空间拥有可用能力与授权资源。对话承载交互，可关联多个任务；任务拥有目标、
执行状态、发现和成果。前端不自行推断一条消息是否开启新任务，以服务端关联为准。

桌面结构：

```text
工作空间名称              业务能力组 · 已启用 N 个        连接状态
任务/对话列表    当前任务标题 · 状态        [查看进展] [查看成果]
                对话与阶段发现             按需打开的进展/成果侧栏
                用户补充、问题和回答        版本、依据、下载
                输入框 · 附加资料 · 发送
```

初始页面以输入与已有任务为主，无电网图、空研究面板或空成果栏。
运行中不因每条事件抢焦点或自动切换面板。首次成果在对话中显示可打开的卡片与成果计数。
用户显式选择后再打开侧栏。专业模型作为“资料与对象”中的一种资源按需打开。
首版保留已有专业网络视图，不能为通用任务加载默认示例网络。

在窄屏中，任务内使用对话、进展、成果三个视图，切换保留草稿、选中产物与滚动位置。
不将窗口宽度变化视为任务切换。业务能力与资源管理从同一任务头部进入。

## 三种请求的同一入口

| 请求 | 默认呈现 | 按需增加 |
| --- | --- | --- |
| 解释彩虹 | 一次请求与回答，真实执行状态 | 用户要求来源或图文产物时增加对应内容 |
| 今天的国际要闻 | 回答与来源，显示采用的日期 | 检索失败或时间范围歧义作为局部提示 |
| Demo1 | 对话、阶段发现、数据缺口、报告与附件 | 研究记录、分析文件和来源详情 |

页面依据实际事件和产物展开，不按题目关键词判断布局。请求被接受不表示已开始执行；
已有skill可直接完成的任务不强制显示计划阶段。没有阶段发现时显示真实运行状态即可。

## 业务能力组

每组显示名称、用途、开关和可用性：未启用、可用、部分资源不可用、暂不可用。
能力组可以已启用但暂不可用，不能把健康状态混同用户选择。
展开显示所含Pack、skills/MCP及依赖状态，版本与详细来源放在详情中。
不在一般任务流程中要求用户配置工具参数、原生依赖或理解Pack内部拓扑。

开关采用草稿选择与明确保存。保存时显示提交中，成功以服务端确认的修订为准；
失败保留草稿与错误提示，并继续显示实际生效状态。并发变更时重新获取配置，
展示差异供用户重试，不无声覆盖其他客户端选择。
活动任务显示“本次使用的能力”与工作空间新配置的差异。
禁用时说明新的相关调用会停止；已发出的动作能否取消由实际回执决定。
不额外弹通用确认框，涉及具体外部动作授权时沿用应用对应审批规则。

全部禁用时仍可阅读历史和成果；发送按钮旁提示需启用业务能力组并提供入口。
服务端同样拒绝执行，不能只靠按钮禁用保证边界。
通用执行组不以模型准备、pandapower或PyPSA worker健康作为启动前提。

## 输入、目标修订与资料

输入框显示当前任务标题及有界的本次资源摘要；资料选择来自现有授权目录或受控上传。
文件上传中、可用、失败各有状态。未完成上传的文件不能静默作为已提交附件。
附件未就绪时允许明确“先发送文本和可用资料”，待上传项保留并显示未提交，不隐式视为已提供。
发送失败保留文本和已上传资料，重复提交使用同一command_id直到获得回执。
执行中补充内容按服务端能力排队或在行动边界纳入目标修订，不伪装已即时生效。
相关追问可延续当前任务；新任务入口显式创建新Work，历史对话保持可访问。

资源缺口卡片说明缺少什么、影响哪些结论、已有部分是否可继续。
可以补资料、回答问题或明确调整目标；没有理由时不要求用户反复批准普通分析步骤。
用户缩小范围产生目标新版本，不把旧目标覆盖为从未提出。

## 任务状态、连接状态与操作状态

三类状态分别存储与呈现，不互相推断：
局部工具/检查失败显示在对应行动或成果，不将整个会话渲染为失败。未核验成果在授权范围内
仍可查阅，显示保证范围；检查建议不自动弹出阻断性审批。等待只用于确需用户介入的情况。

| 任务状态 | 呈现与操作 |
| --- | --- |
| 排队/运行 | 显示当前实际状态，可提交暂停或取消请求 |
| 等待输入 | 显示待决问题，允许补充后继续 |
| 已暂停 | 显示已保存进展，可继续或结束 |
| 部分完成 | 已有产物和未完成要求并列，允许继续 |
| 已完成 | 显示结果与验收范围，允许提出后续要求 |
| 失败/已取消 | 显示原因、已有成果及恢复选项，不删除历史 |

连接断开显示“连接已断开，后台状态待确认”，不是“任务已停止”。
暂停命令先显示已请求，收到生效事件后才显示已暂停；不可中断的调用显示等待结束。
外部动作结果未知独立显示，不能直接提供盲目重试按钮。
恢复前如授权或资源版本失效，说明实际缺口，不直接重放旧请求。

## 进展、依据与成果

进展显示任务级发现、方法修订、缺口及真实检查结果，不显示隐藏思维。
工具日志按需展开。判断有明确来源与状态，模型写出的判断不自动标为“核验通过”。
修订关联旧判断，前端标明旧结论已撤回或待重验；不能只追加一条互相矛盾的新结论。
报告和图表也呈现与当前输入/目标版本的关系。旧成果可查，但不能默认当最新成果下载。

成果包括文字回答、文档、图表、表格和其他文件。专业计算结果继续使用现有投影视图；
通用成果不伪造model_id以复用专业组件。产物卡展示标题、类型、版本、创建时间、
可用性及检查摘要。大文件不在浏览器全量解析；按服务端允许提供预览或下载。
损坏、缺失、过期、无权限或超限显示具体状态，不把有文件名当作文件已可用。
不支持安全预览的文件仅下载；HTML等活动内容不得直接在应用同源中执行。

依据详情展示来源、获取时间或版本、所用方法及结果引用；技术标识可进一步展开。
当前任务的一般来源和专业Authority证据保留不同标识，不用单一绿勾抹平验证范围。

## 协议对接与恢复

以下是新增公共投影职责，不是已存在的端点承诺：

| 投影/命令 | 必需内容 | 前端行为 |
| --- | --- | --- |
| 工作空间配置 | workspace_id、revision、Profile身份/版本、用户选择、可用性及原因 | 真实开关状态，不依附activeModelContext |
| 任务快照 | work_id、thread_id、目标修订、执行状态、配置快照、最后事件序号 | 刷新后恢复同一任务 |
| 任务事件 | work_id、sequence、attempt_id、类型、配置修订及有界载荷 | 去重、检测序号缺口，补取后再更新 |
| 成果投影 | artifact_id、revision、类型、大小、检查状态、依赖及访问状态 | 选择版本、预览和授权下载 |
| 用户命令 | command_id、目标身份、expected_revision及请求内容 | 区分已接收与已生效，冲突不无声覆盖 |

客户端只消费公共投影。服务端持久状态为真相；本地缓存保留草稿和视图偏好，
不能据缓存断言任务已完成或权限仍有效。首次快照带事件游标，后续流从游标衔接。
重复、乱序、断线和保留期外游标要有测试；需要重新快照时保留用户草稿。
禁止通过刷新重新发起已有任务；身份相同的命令重试返回原回执。

## 验收

- 无电网模型创建任务且不加载示例图，专业worker不可用不阻止具备条件的通用任务。
- 简单问答、新闻查询和Demo1从相同输入进入，按真实内容展开，无强制研究面板。
- 保存能力组成功/失败/冲突、禁用活动资源和晚到结果，界面与后台生效状态一致。
- 断线、刷新、重复事件、事件缺口和过期游标不丢任务，不重复执行，不丢草稿。
- 报告与附件可访问，错误状态清晰；修订后旧图表标识正确，不能下载错版本。
- 键盘可操作能力开关、任务动作与面板；状态文字可被辅助技术读取，不依赖颜色。
