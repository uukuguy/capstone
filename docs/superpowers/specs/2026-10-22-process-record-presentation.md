## Reading behavior

- Embedded steps default to folded. The heading retains number, purpose, concise
  status and actual elapsed/tool/LLM measurements. A bounded two-line excerpt of
  the actual saved result remains visible. No result is inferred from a status.
- Reader steps default to expanded. Explicit manual choices override defaults.
  Embedded and reader preferences use separate storage scopes.
- Individual and bulk fold choices survive updates, completion and remounts.
  A prior bulk command must not overwrite a later manual choice after remount.
- Top-bar icon buttons have accessible names, tooltips and keyboard focus.
  Expanding steps does not expand raw outputs or diagnostic records.
- Parallel groups retain their existing indent and elapsed/tool/LLM accounting;
  folding changes presentation only, never execution or accounting.

## Detail hierarchy

The graph adapter uses peer disclosure groups: result, task and execution.
Result and task open initially; execution opens on demand. Explicit saved user
choices override these defaults. The task group shows
questions, expected products and check requirements. Long native instructions,
IDs, source/result versions, prior executions and accounting caveats belong to
diagnostics. Tools appear directly under execution, with no second tool-group
disclosure. Raw individual tool output and references remain separate disclosures.

consistent disclosure spacing, readable text measure and secondary metric text.
Internal horizontal rule lines and duplicate rails are removed. Each main step
has a thicker vertical rail; parallel steps have separate thin rails and an
indent. Step chevrons stay at the left beginning, while overall fold controls
and enlargement form a compact right toolbar. The reader close icon is small
and flat. The record has outer gutters and spacing between rails and content.
Status text remains explicit; a subtle
status surface supplements the text. Reader result text is slightly larger than

Source summaries and historical output remain available. The layout does not
