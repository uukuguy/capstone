# Skills 与 MCP 持久安装设计

状态：用户已确认产品方向及预安装清单；权限、持久登记、安装适配、工作空间 API、任务内使用与工作台管理已实现，正在本机集中验证；依赖环境、受保护凭据绑定与离线预装部署闭环尚未完成。

## 已确认的行为

- 安装默认持久保存，不区分临时和永久安装。
- 安装资源在当前工作空间内跨会话可用；任务仍按需发现和加载。
- 指令结束、浏览器关闭及服务重启均不卸载资源。
- 提供安装、启用、停用、更新、卸载；资源文件和配置独立于任务临时目录。
- 本机运行默认开放应用功能权限；内网安装部署采用收紧的默认配置。通过配置限制，不能绕过权限检查或要求修改执行链。
- 本决定没有授权关闭任务隔离、凭据保护、数据源授权或专业结果准入。

## 统一权限入口

应用负责工作空间授权。页面操作、对话发起、管理接口及恢复中的安装作业
均调用同一权限判定函数。不得只隐藏前端按钮，也不得由模型判断是否有权限。

建议动作标识为 `resources.install`、`resources.enable`、`resources.disable`、
`resources.update`、`resources.uninstall`、`resources.use`。它们是拟新增的应用权限，
不是现有网关工具或当前已经生效的配置。

判定输入为可信的主体、工作空间、动作、资源及当前策略版本；主体和授权范围由
后端取得，不接受模型自行填写管理员身份。本机开发配置显式允许以上全部动作，
保留统一判定路径。内网部署默认允许使用已启用资源，安装、启停、更新、卸载及
预装清单管理默认关闭，授权管理员再按配置开放。应用功能权限与任务隔离、
业务数据访问及网络开关分别控制。未知动作与无有效策略不能默认为允许。

权限配置由部署明确选择，不根据浏览器地址、客户端IP、操作系统或模型文字判断。
内网免登录访问不等于管理员；管理身份只能来自后端验证的认证上下文。
新增配置必须覆盖本机与内网部署入口，避免内网继承本机开放默认值。

策略变更对后续操作生效，无需重建镜像。安装作业开始和发布前均检查当前权限，
避免排队中的安装在权限关闭后仍发布。关闭安装不自动停用已有资源；关闭使用或
停用资源阻止后续调用，进行中的调用保留真实状态，不伪造取消成功。

## 持久安装与运行

应用资源管理服务拥有登记、范围、版本和权限。安装器适配 Skill、远程 MCP 和
本机运行的 MCP；中立执行层只消费已准入的资源引用，领域语义仍属于相应提供方。

共用流程为解析来源、隔离获取和安装、校验、实际加载、原子登记、发布能力。
使用现有任务作业和事件机制记录进度，避免另建独立任务账本。安装请求应幂等；
同一资源并发安装使用锁。失败只清理未发布暂存内容，保留原可用版本。

数据库保存资源身份、工作空间、来源、精确版本、摘要、启用状态和安装回执；
包文件及依赖保存在独立持久存储，任务取得已准入版本的只读引用。
凭据只保存后端保护引用。重启读取登记并校验恢复，不自动下载或升级。
运行环境与依赖不兼容时明确报告不可用，不能静默替换版本。

Skill 通过现有 Pi 资源加载机制接入。本机 MCP 由受管运行环境启动；远程 MCP
保存连接配置，使用时连接并发现能力。通用 MCP 不要求实现 data-gateway 的专用入口；
网关约定仍只属于该适配器。工具名、参数及描述来自实际发现，名称映射和参数校验由代码完成。

安装、启用、可用分别记录。成功提示必须反映实际加载或连接结果，不能只依据下载退出码。
资源获取受当前网络设置约束；研发管理权限全开不改变外网开关。

## 当前任务与历史

安装成功后，应用可在工具调用边界发布新的资源集合版本，让当前指令继续使用。
已执行步骤仍引用原集合；后续步骤记录新集合。不能覆盖历史契约、调用和结果。
更新生成新版本；卸载先撤销未来使用的绑定，再按任务引用和保留策略回收文件。
安装资源本身不授予业务系统访问权，不改变当前会话的数据网关实例绑定。

## 实施范围与验证

### 预安装清单（2026-11-02用户确认）

预安装表示随选定应用部署配置提供的默认资源。已安装资源提供“加入预安装清单”
操作，生成清单草稿条目；记录当前已验证版本、内容摘要、依赖锁定、默认启用状态
和适用环境。该操作不会立即发布或改变其他部署。权限单列为建议动作
`resources.preinstall.manage`；本机默认允许，内网默认关闭，不与普通安装权限混同。

清单经发布成为带版本的部署配置。Skill和本机MCP携带可离线部署的包及依赖，
按目标运行环境构建或验证；远程MCP预配置连接，不代表将远端服务打包。
凭据和环境地址在部署时绑定，不从个人安装中复制明文凭据。

资源列表区分“已安装”“已加入预装草稿”“已随部署提供”。增加清单不等于已经部署。
预装资源使用与普通安装相同的资源登记、加载、工具发现与权限机制。
新部署或新工作空间按选定配置获得默认资源；现有绑定和执行中的版本不被静默覆盖。
同一资源的工作空间版本覆盖需显式登记；更新清单、撤销预装与普通卸载分别处理。
撤销预装仅影响后续部署的默认清单，不直接删除现有工作空间的安装。

清单条目是可安装的Skill包或MCP服务，不是复制某个MCP工具方法的实现。
MCP工具名和参数仍在连接后动态发现。预装部署沿用既有发布流程，CI仍需用户明确同意。

实施顺序：持久登记与统一权限接口；共用安装作业；三种资源适配；当前任务加载；
工作台管理入口。沿用 NativeResourceStore 的版本快照机制，扩展现有固定样本安装器，
不在主链路加入资源或业务工具的名称特例。

重点验证：本机允许、内网默认拒绝管理操作；配置关闭后的所有入口拒绝且无安装副作用；排队作业权限撤销；
重启及容器替换恢复；失败回退；跨会话使用；更新与历史版本隔离；卸载引用保护；
断网时已有本机资源继续可用、远程资源明确报告连接状态。
按改动运行定向检查。未经用户明确同意，不启动 CI。
