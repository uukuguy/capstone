# 基于引用与执行过程原语的任务推理执行

状态：用户确认值得设计实现并验证，尚未实现或完成安全评估。

## 动机

将绑定真实数据的取数、确定性计算和分析置于内网网关；Capstone 使用 query_ref、dataset_ref、result_ref 组织任务推理和执行。即使不能满足严格禁止信息出境的要求，减少模型上下文、重复取数和逐页往返也值得验证。效率、分析能力和数据安全分别评价，不相互代替。

外部模型负责方法、观察角度、基线与调查方向；网关负责数据绑定和确定性执行；Capstone 负责目标连续性、授权、调度、证据准入和用户交互。用户可随时跳转，工具集没有固定使用顺序。具体行动只受输入依赖、授权和当前状态约束。

## 原语及所有权

| 层 | 职责 |
|---|---|
| 网关能力 | 准备查询、取数、选择与变换、比较、质量检查、事件和窗口、任务推进、不可变结果引用 |
| Capstone 执行机制 | 受控调用、独立批次、依赖续进、预算、取消、结果准入、检查点和恢复 |
| 调查判断 | 目标关联、候选解释、下一项观察、复核、阶段交付和用户纠偏 |
| 内网成果生成 | 根据数据与发现引用生成图表、CSV、报告；绑定版本并局部修订 |

不把业务工具名、固定迎峰度夏流程或提供方名称编码进通用执行链。根据实际发现的契约和显式返回动作组合能力。缺少机器可读依赖或续进信息时记录缺口，不凭名称自动推断。

现有网关文档提供查询、数据、结果和任务引用。发现引用、语义反馈、引用驱动报告及局部修订是需核查和补齐的候选能力，不能视为当前网关保证。

## 引用和执行语义

query_ref 表示已准备请求；dataset_ref 表示数据集；result_ref 表示分析结果。不同用途的 plan_ref 不互换。累计续取保存最新选定引用及祖先关系，覆盖核验不能重复累计祖先页。

引用需绑定任务可用范围、实例、提供方和环境。引用本身不是用户授权凭证。切换实例保留历史成果，但不能把旧引用直接送入新实例。契约版本不是源数据版本，未知新鲜度保持未知。

复用已有 tools.map 和调度机制，独立且允许并行的调用有界执行；依赖链按返回结果推进。分页、显式分析推进、状态读取分开处理。条件确定的机械循环可由受限程序执行，语义选择返回模型。未声明只读或副作用的工具不能擅自并行。

恢复读取已提交检查点，核验来源和引用，再继续未完成行动。未知副作用先核验，不盲目重放。检查点包含目标修订、选定输入、发现及证据、成果、待办、预算和停止原因。

## 模型可见性与安全评估

分别试验三种投影：仅不透明引用与必要控制状态；引用与结构化发现；引用与允许的统计摘要。后两种属于衍生信息出境，不能称为零数据出境。仅引用会限制模型依据实际结果调整策略的能力；数据相关分支需由内网执行。

完整会话留在内网，对外上下文按允许结构构造。输入、工具描述、返回、错误、历史、报告、日志和遥测均纳入检查。外部临时别名映射到内网引用，不授予下载或读取明细能力。默认拒绝未定义字段外发，敏感扫描只作为附加检测，不能作为唯一防线。

把数据计算权限与对外读取权限分开。引用驱动计算不自动允许明细读取；真实报告直接呈现给内网用户。外部提出的计划和代码仍需授权、输入输出校验、网络隔离与预算约束。

任务结构、结果是否为空、错误、分支及时间也可能泄露信息。记录各模式实际可见内容及剩余风险，不宣称绝对安全。如全部业务衍生信息均禁止出境，外部模型仅提供通用方法，事实解释和数据相关判断留在内网。

## 首个真实验证：迎峰度夏

以同一授权范围、数据和交付目标，对照当前执行与引用执行：绑定范围和指标，准备目标与参照，有限取数，复用数据完成质量和比较，追查一项发现，生成 PPT/CSV；用户修改基线或对象后局部更新，停止或刷新后继续。

上述是验收覆盖，不是规定的调用顺序。另覆盖从已有数据直接分析、从已有报告直接修订，以及中途转向后返回。没有气象、容量或运行约束证据，不推导因果或供电风险。

记录首个有用发现及成果时间、模型调用和上下文量、源请求及字节、重复取数、错误、总耗时和恢复成本。记录结论正确性、覆盖限制、证据可追溯性、修订质量，以及因语义反馈不足而损失的能力。通过出境报文审计与标记敏感数据检查评估泄露；再用另一业务主题检查通用性。

## 实现顺序

1. 盘点现有默认执行链实际使用的工具组合、研究状态和引用准入，形成能力缺口表。
2. 以现有执行通道接通一个引用取数—分析—成果闭环，保证逐调用记录、取消与恢复。
3. 实现独立的模型上下文投影与出境约束，先在本地记录拟外发内容；审查后再接外部模型实测。
4. 支持结构化发现反馈与用户跳转后的引用复用，进行三种投影的效果比较。
5. 完成真实多轮对照，按证据决定扩展原语、反馈粒度和部署范围。
