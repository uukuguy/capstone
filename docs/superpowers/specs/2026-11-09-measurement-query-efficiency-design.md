## Capstone-owned scope

1. Reproduce and fix neutral helper namespace inconsistency: global python and
   tools.python must be the same granted private-workspace helper; publish its
   exact signature in tools.help. No new execution or host permissions.
2. Preserve bounded corrective JSON-Schema diagnostics. Missing required property
   paths and numeric bounds come from the admitted contract, never argument values
   or arbitrary upstream error text. Keep validation refusal fatal to that call;
   do not retry or rewrite business arguments automatically.
3. Describe the actual composition envelope and helper namespaces. A model can
   inspect/read/repair local paths within one program; known response contracts
   do not mandate a separate discovery/inspection model round. Follow only issued
   version/grant-checked actions and actual dependencies. Never infer tool choice
   or reference conversion from business field names.
   Within the existing structure-index budget, expose populated arrays/objects
   before empty slots and mark omitted keys/containers as partial. Preserve the
   original response and values; do not infer semantic field importance.
4. Keep requested output scope. A bounded display request does not automatically
   require full-dataset statistics, CSV products or a report. Use saved source
   observations for any requested export; do not reconstruct numerical arrays
   from reader-facing prose.

Operational transport correction: a protected loopback connection may be reached
through the configured Docker host alias. Its private generated client config
retains the original loopback authority, with the same port; the MCP HTTP client
uses it as Host. The registry/API still accepts only its existing URL/token/name
inputs and Authorization header. No arbitrary Host input, new endpoint permission,
DNS-rebinding disablement, redirect or ambient proxy is introduced. Non-loopback,
credential-bearing, path-bearing, cross-port and control-character authorities
are rejected. This preserves HTTP authority; it does not alter TLS verification.

Gateway owns source-supported name/relationship resolution, schema bounds,
typed source references, exact result shapes and next-action publications. Do not
hardcode station/device/metric/table semantics, guessed paging, key_ref conversion
or hidden source limits in Capstone or Kernel. Existing ownership, evidence,
permissions and asynchronous waits remain enforced.

## Capstone selection projection follow-up

The user requested continued Capstone work after forwarding the joint report.
The frozen joint catalog reproduces two adapter defects: a query containing a
published tool identity returns tools whose descriptions merely mention it;
raw metadata prefix slicing hides complete declared prerequisites. These are
projection defects, not proof that fixing them meets model efficiency targets.

Recognize complete whitespace-delimited registered/published identities before
description matching, preserving exact-name ambiguity and task grants. In the
gateway adapter, project capability-summary/1 provider-declared selection fields
as complete JSON values within the existing per-summary character budget. Mark
omitted fields; never truncate a policy clause into an apparent complete rule.
Use the same projection in search and direct tool descriptions so an activated
tool retains its declared conditions. Preserve exact input/output schemas,
full publication access through tools.describe, capacity checks and model choice.
Unknown summary versions retain the existing generic metadata preview.

Alternatives: more global prompting lacks mechanical visibility guarantees;
business-specific tool ordering violates ownership. Select the bounded adapter
projection instead, with tests for grants, ambiguity, omitted text and actual
SDK model menus. Then freeze publication/model and run one original-instruction
trial. Attribute only with matched catalog identities; retain failed targets.

Existing tests also reproduce small load receipts becoming file previews because
the full shared guidance alone exceeds their context budget. Keep that guidance
in before_agent_start and composition context; search/load return a short reminder
instead of duplicating it. Small activation receipts must stay directly readable.

Gateway feedback and the second real trial expose a missing protocol path:
progressive packets contain provider declarations, but the adapter drops them
while telling the model not to initialize again. Preserve declarations in the
publication fingerprint, require page consistency, scope them to admitted
providers, and project complete text into task context. Selected exact contracts
also retain fingerprint-checked usage metadata, without JSON-Schema validation
of that metadata. Verify actual SDK context, not just packet receipt. These are
provider declarations, not source facts, tool grants or a mandatory first action.
