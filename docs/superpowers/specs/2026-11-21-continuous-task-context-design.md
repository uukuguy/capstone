# 持续任务上下文与三级执行设计

状态为设计基线。产品实施与验收按[工作计划](../plans/2026-11-21-continuous-task-context.md)逐包登记。

## 用户契约

会话可以从自由 Instruction 开始。问题、讨论对象和已有资料即可形成上下文，目标和完成标准允许为空。用户可以结束讨论，也可以沿用它继续办事。同一会话可以处理旁支和不同任务。任务引用与会话身份分别保存。

同一目标可用三种机制完成。普通输入沿用当前交互语境；新委托默认 Instruction。只有用户明确选择才启动顶层 Goal 或 Mission。工作量、耗时、关键词与工具数量均不能触发升级。

| 机制 | 执行责任 | 结束依据 |
| --- | --- | --- |
| Instruction | Harness 在一次指令内持续推理、调用工具、压缩和恢复。自由提问可直接回答。 | 正式答复、适用的交付与缺口已保存。 |
| Goal | 主会话 Agent 自行规划并执行多轮 Instruction。每轮依据新事实调整下一步。 | Agent 根据最新目标和校验条件给出结论，由应用核验绑定并归档。 |
| Mission | 主会话组织者可独自执行，也可建立子会话。每次委派独立选择 Instruction 或 Goal，按需混用。 | 组织者核对总目标、可用子交付和剩余缺口，在主会话统一交付。 |

## 上下文记录与所有权

capstone-agent 复用 Work、Attempt、消息和制品记录；capstone-control 拥有 Mission 计划、委派与组织者复盘。App 读取有界投影。沿用领域 Authority 的版本和证据准入。普通工具产物保留自身来源。

每个上下文版本包含稳定任务引用、版本及前版、来源会话和事件边界、执行机制、当前工作区授权引用、用户方向和约束、校验条件、已完成与待做项、缺口、活动执行绑定、制品与证据引用。字段按需填充。每项指导和结论可定位到原消息或真实执行。历史大文件按版本引用，按需限量读取。

复用同一权威写入方。消费操作带预期版本、操作身份、执行代次。原子提交新事实与待执行意图，重复消费返回原处置。旧代次结果可留存，须按最新约束复核才可进入交付。模型决定行动及业务含义；服务检查授权、版本、引用、状态转换与副作用去重。

## 推进、干预与结束

接纳用户输入、工具返回、子交付或恢复回执后，先保存事实，再判断下一项可执行工作。允许同一句话同时改变方向、边界和校验要求。在普通查询进展时回答当前状态，主线继续。修订目标时标记受影响的后续计划并继续。插入非主线指令时先冻结 Goal 续派位置，再运行旁支；在途结果保留原绑定。`/goal resume` 基于最新有效状态恢复，同一条命令重放只派发一次。

工具不足时检查工作区已安装资源及授权替代路径。用户可自行配置；具备授权时 Capstone 可通过既有 managed-resource 契约安装、加载、验证确切版本。记录安装回执、实际加载和成功使用。越权步骤只影响其依赖项。独立步骤继续。截止、预算耗尽、持续无进展或无法取得关键资料时，保存可用工作并明确结论。归档、交付程度（完整、部分或无法完成）及用户意见分别记录。无需用户例行确认。用户主动暂停、停止优先于待派发步骤。

## 压缩、崩溃恢复与跨会话继续

自动压缩按执行上下文预算触发。保存摘要的来源区间、生成版本、未决操作和原记录引用。每次装配从持久记录重载当前有效约束、授权和校验项，防止重复压缩丢失要求。摘要不得创建证据或扩大权限。压缩失败时保留前一有效恢复点，优先装配当前必需记录。

关键边界增量保存。发出副作用前持久化操作身份，返回后绑定回执；会话正常结束时保存最后位置。异常退出从最近提交恢复。对未知结果先查原操作；无法证明安全重试时保留诊断并继续独立工作。禁止凭超时再次发出非幂等动作。

新会话显式加载获准版本，按目标会话权限重新解析资源与证据。历史回看和已有的版本化交接继续可用。若用户要接管仍在执行的同一任务，建议采用单一有效执行代次，通过条件写入转移推进权。原会话保留历史和回看能力。独立派生任务使用新身份。刷新页面仅恢复阅读与订阅。

## 主会话呈现

复用企业工作台的输入框、正式答复、成果区和执行详情。自由问答直接回复。Goal 展示当前方向、已交付、正在做什么及下一步。Mission 在同一位置增加可展开的委派、依赖和局部缺口。每次指导显示实际影响；结束时逐项链接校验结论和产物。当前摘要从持久记录计算，刷新后可重建。使用已完成事项表达进度；无可测分母时不显示百分比。用户仅在主会话交流，无需填写任务表单或进入子会话操作。
