# 给 data-gateway 的接口决定：调查归属与回执读取范围 v1

2026-11-25 双方确认接受 v1。Capstone 核验工作空间、Thread 和调查归属。网关认证专用服务主体、在派发前登记绑定，并在读取时复核当前授权。首轮以同一主体的两个工作空间验证断连后按 client_call_id 查回、跨绑定拒绝及重复提交只派发一次。正式操作名、Schema、版本及样例待网关发布。浏览器继续使用部署级调试开关和现有 Thread 权限。

## 信任建立

现场给 Capstone 后端连接配置专用服务凭据，在目标网关登记稳定的调用方主体，并显式授予该主体建立调查绑定的权限。只读业务 Bearer、实例主 Bearer 和调查管理权限各按现场配置核定。共享给其他客户端的凭据不能作为此专用主体。现有连接已使用 Bearer，首版复用认证传输。跨主机需有受保护的传输通道。

Capstone 服务端检查部署开关、当前工作空间、Thread、调查及选定连接。从自己的持久账本取工作空间和调查的稳定 ID。网关信任已登记的 Capstone 主体在此范围内作出的归属声明；不接受模型、工具参数、浏览器或诊断元数据提供的身份。多个工作空间可共用一个 Capstone 服务主体，网关依靠可信后端正确绑定。这是明确的信任边界。

## 建立、记录、查回

1. 后端通过仅服务端可调用的版本化操作提交归属、连接实例和幂等键。网关核验主体及当前业务授权视图，生成不透明随机调查句柄，绑定主体、网关实例、工作空间、调查和授权范围。建立操作重试返回同一有效绑定；相同键配不同归属须拒绝。网关声明有效期、撤销和诊断保留期限。
2. 调用前，Capstone 持久化待派发记录及唯一 client_call_id。适配器在协议层附带调查句柄；沿用 gateway/diagnostics 传递关联信息。网关核验句柄与主体、当前业务授权相容，在派发前持久化此次调用和绑定的关系，并在收到结果时补记 request_id、状态及允许公开的摘要。绑定失败时禁止以已绑定名义派发。同一绑定内重复的 client_call_id 不重复派发，参数或操作不一致须拒绝。
3. 读取需要当前已认证主体、有效绑定、当前诊断读取权和目标调用的持久归属。查询先限定绑定，再按 client_call_id 或 request_id 定位。列表、分页游标及阶段明细遵守同一范围，重新检查当前授权视图。授权收窄后不得凭旧绑定读取已撤销范围。跨绑定、无权限与未知 ID 的对外响应不能泄漏目标是否存在。业务授权不得由调查绑定扩大。
4. 响应丢失时只查原 client_call_id。记录未找到、绑定前旧调用、数据裁剪和远端结果未知均无权触发自动重发。业务请求与诊断落账之间出现中断时保留不确定状态。返回已观察范围、裁剪和保留限制；如需分页或稍后续查，返回明确的续查条件。调查关闭后停止追加；历史查阅需要仍有效的读取授权。过期后的重新绑定必须核对原归属，禁止客户端自行认领旧请求。

句柄与凭据仅由两端受保护组件持有。不得进入浏览器、Pi 上下文、业务参数、诊断日志或导出物。句柄本身不能授权。版本和具体操作名由网关正式发布；Capstone 只在适配器中处理协议名称。

## 当前兼容路径与共同验收

### 新增需求：Debug Pi 主动查询网关运行日志（待网关确认）

除阶段摘要外，请发布版本化的只读调查日志能力，可作为回执的分页明细或独立 MCP 操作。正式名称由网关发布。Capstone 适配器注入主体及绑定，Pi 使用调查内调用引用，自主选择组件、严重级别、时间范围和下一页。用户可以从右栏打开 Pi 引用的同一片段。操作不得接收任意文件路径、宿主机命令或未授权的实例选择。

返回该绑定已登记调用的已脱敏日志行，保留时间、组件、阶段、错误消息、必要的异常链、前后文、稳定记录引用、关联依据、裁剪和保留状态。参数、凭据、SQL 值与业务正文遵守现场日志策略。调用级查询不能借时间窗扩大到同一服务主体下另一工作空间的请求。启动、重启、崩溃等无法直接关联的实例事件，只有网关能按独立授权投影为可公开的服务生命周期事件时才可返回；显式标注“同实例时间相关”，不得从混合日志中返回其他调查的消息。现场可读与允许外带分别声明。

请提供合成样例，覆盖一次调用的错误和上下文、绑定外请求拒绝、分页与轮转、无日志和日志被裁剪。响应丢失沿原 client_call_id 查回，不触发再次派发。旧网关未声明此能力时，Pi 可继续使用已有业务回执并注明日志不可见。本项是原首轮三项联验以外的新需求。

请随正式 Schema 提交字段外带说明：哪些回执字段可导出，哪些仅可在现场查看，哪些需要聚合或替换成合成值。对未声明外带权限的字段，Capstone 默认仅在现场查看。说明裁剪、过期、未观测及查无记录的区别，并提供可提交到本机测试仓库的合成请求和响应。请给每项样例标注契约版本、预期状态和判据。网关负责授权读取；Capstone 负责右栏展示、导出策略执行、复现包和本机回放。此补充不改变首轮联验范围。

旧网关继续使用已授权目录、精确契约、只读调用和本次响应的 provenance。响应丢失标记“网关结果未知”。已发布业务异步操作按原契约和原任务引用续查。工作台 /api/diagnostics 保留为现场运维入口。新绑定仅覆盖创建后的调用。研究旧 Attempt 时可用 Capstone 原先已保存的回执。

双方联验同主体下两个工作空间、同工作空间两项调查、另一服务主体、伪造关联 ID、撤权、过期、重复派发、发出后断连、分页裁剪及旧网关降级。真实回执须验证成功与部分结果。国调工具在目标实例单独验证。本机 64 项工具只代表本次实例发布。
