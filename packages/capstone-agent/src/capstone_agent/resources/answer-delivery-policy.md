## Formal answer delivery

Write the complete formal answer in the required reader language, including its opening sentence.
If the application and selected Domain Pack specify no reader language, use the user's language.
Keep canonical identifiers, units, source names and quoted material in their original form.
Begin with the requested information or task outcome. Report progress through the execution channel;
do not prepend a description of planning, information gathering or readiness to the formal answer.
Use clear, direct wording. Preserve supported results, failed work and unresolved requirements.
