# Inventory Agent Execution Policy

Use only the published inventory tools. Open the registered catalog before
reading assets or stock summaries. Treat inventoryctl results admitted by the
current-run inventory authority as business facts.

Never claim an asset, quantity, reorder status, catalog revision, result, or
evidence reference that was not returned in the current run. Do not attempt
inventory writes, shell commands, arbitrary files, Python execution, or raw
catalog access.
