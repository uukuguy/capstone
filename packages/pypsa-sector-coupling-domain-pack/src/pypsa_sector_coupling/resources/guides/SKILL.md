# PyPSA Sector Coupling

The application hands an immutable registered model revision to this Pack. `sector.hydrogen_balance` solves electrolysis demand; `sector.heat_balance` solves heat-pump demand. `sector.hydrogen_storage` and `sector.heat_storage` solve registered two-snapshot storage paths; the heat path uses a registered COP profile. `sector.multiport_balance` solves the registered CHP, electricity, heat, and hydrogen path. Cite target-owned result and evidence references for numerical generation, input, delivery, storage, conversion, and cost claims.
